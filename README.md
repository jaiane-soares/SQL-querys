# Modelagem de dados e consultas SQL

---

## 📌 Sobre o repositório

Este repositório foi desenvolvido para centralizar, organizar e documentar diferentes estudos de caso envolvendo a modelagem de bancos de dados relacionais e a escrita de consultas SQL (DDL, DML e DQL). 

O foco principal é estruturar soluções eficientes para problemas de negócios reais através de:
 **Modelos Entidade-Relacionamento (MER)** bem estruturados e normalizados.
 **Scripts DDL** robustos com aplicação estrita de restrições de integridade, chaves e relacionamentos.
 **Consultas SQL (Queries)** otimizadas utilizando junções (`JOINs`), funções de agregação, subqueries e agrupamentos.

---
